    \begin{lstlisting}[language=C,basicstyle=\ttfamily\small,caption={Inicialización mínima y lectura de ángulo XY (TMAG5170 A1).},label={lst:tmag_min_init}]
    void tmag5170_init_angle_xy(void)
    {
        tmag_disable_crc_once();  // opcional durante pruebas (ver datasheet)
        tmag_write16_nocrc(0x01, TMAG_SENSOR_CONFIG_VAL);  // SENSOR_CONFIG
        tmag_write16_nocrc(0x00, TMAG_DEVICE_CONFIG_VAL);  // DEVICE_CONFIG
        tmag_write16_nocrc(0x03, TMAG_ALERT_CONFIG_VAL);   // ALERT_CONFIG
    }
    
    float tmag5170_read_angle_deg(void)
    {
        uint16_t raw = tmag_read16_nocrc(0x13);  // ANGLE_RESULT
        return (float)(raw >> 4) + (float)(raw & 0xF)/16.0f;
    }
    \end{lstlisting}

    
  
\section{Pruebas con el \textit{driver} de motor}
\label{sec:pruebas_driver}

Para las pruebas con el \textit{driver} VNH7070BAS se empleó una etapa de potencia basada en el puente H seleccionado en el Capítulo~\ref{ch:CH04-Diseno-Electronico}, con el objetivo de validar su funcionamiento antes de integrarlo al prototipo final. En esta etapa se verificó la correcta excitación del motor \ac{DC} mediante señales de control provenientes de la ESP32 (habilitación, sentido de giro y \ac{PWM}), así como la lectura de la salida de sensado CS para su posterior adquisición por el ADC. Las pruebas se realizaron en un entorno de prototipado rápido, utilizando conexiones accesibles y puntos de medición que permitan observar las señales principales del \textit{driver} y confirmar su compatibilidad con la lógica a \SI{3.3}{\volt} del microcontrolador.
